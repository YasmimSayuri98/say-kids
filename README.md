# Say Kids — Sistema de Gestão Escolar de Educação Infantil

Projeto acadêmico (Análise e Desenvolvimento de Sistemas). Sistema web desenvolvido em **HTML, CSS e JavaScript**.

## Status atual
Login funcional para os perfis: **Administrador, Secretaria, Professor e Auxiliar**.

## Como executar
Abra o arquivo `index.html` no navegador.
